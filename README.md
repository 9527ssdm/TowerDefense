# TowerDefense

一个用 Unity 2022 LTS 制作的 2D 塔防游戏，从零独立完成。

## 玩法

- 点击空地建造防御塔，阻止敌人抵达终点
- 撑过 5 波敌人即胜利
- 敌人漏过终点会扣玩家血量，血量归零则失败

### 三种塔

| 塔 | 特点 |
|---|---|
| 单体塔 | 发射子弹，单体高伤 |
| 范围塔 | 范围内所有敌人同时受伤 |
| 减速塔 | 降低敌人移动速度 |

三种塔都能升级到 3 级，伤害和射程随等级提升。

### 三种敌人

| 敌人 | 特点 |
|---|---|
| 普通怪 | 均衡 |
| 快速怪 | 血少速快 |
| 坦克怪 | 血厚速慢 |

## 操作

| 按键 | 功能 |
|---|---|
| 鼠标左键 | 建造 / 升级塔 |
| Esc | 暂停 |
| S | 切换 4 倍速 |
| R | 结束后重开 |

## 技术实现

- **架构**：`TowerBase` 抽象基类 + 三个子类，多态处理不同塔的攻击方式
- **数据驱动**：`TowerData` / `EnemyData` 用 ScriptableObject 配置，加新塔/新敌人只需配数据
- **波次系统**：协程驱动，支持一波混合多种敌人，清场后进入下一波
- **索敌**：`Physics2D.OverlapCircleAll` 找范围内最近敌人
- **对象池**：子弹复用，减少 Instantiate/Destroy 的 GC 压力
- **状态管理**：`GameManager` 单例管理血量、金币、暂停、胜负
- **存档**：`PlayerPrefs` 记录最高波次和通关次数
- **UI**：主菜单、暂停菜单、HUD，Canvas Scaler 适配不同分辨率
